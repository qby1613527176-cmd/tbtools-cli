# tbtools-cli

**TBtools-II 全功能命令行封装** — 218 绘图引擎 + 188 RPC 方法 + 82 工具,Linux/WSL 免 GUI。

- 仓库: [github.com/qby1613527176-cmd/tbtools-cli](https://github.com/qby1613527176-cmd/tbtools-cli)
- 安装: `pip install tbtools-cli`(或 `git clone` + `install.sh`)
- 配置: `tbtools doctor` 自检 → `tbtools setup --auto` / `tbtools fetch-jar`
- 版本: v1.1.0(41 项缺陷修复 + 架构重构 + 七轮审计)
