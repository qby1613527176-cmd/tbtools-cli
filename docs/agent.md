# Agent Interface

tbtools-cli exposes a **structured, machine-readable interface** for AI agents: discover → describe → validate → execute → result → provenance. All outputs are pure JSON on stdout (`schema_version` included); logs go to stderr.

## 7 Capabilities

| # | Capability | Command |
|---|-----------|---------|
| 1 | Discover | `tbtools search <task> --json` — multi-word AND/OR, reverse search `--input gff3 --output svg`, capability filter `--capability phylogeny` |
| 2 | Describe | `tbtools tool-describe <cmd> --json` — id/group/kind/help + inputs/outputs schema + capabilities + dependencies + availability + relations |
| 3 | Preflight | `tbtools tool-validate <cmd> <inputs...> --json` — existence/format/columns, format-match warnings, `--force` to override |
| 4 | Execute | `tbtools tool-run <args...> --json` — **pure-JSON stdout** (Java logs suppressed), `--timeout N` (kills process tree → TB007) |
| 5 | Result | `tbtools tool-result <job_id>` / `tool-provenance <output>` — artifacts + structured error |
| 6 | Status | `tbtools rpc status` (server) / exit codes / `job-status` (task state machine) |
| 7 | Env | `tbtools env --json` / `env --lock` — environment snapshot for reproducibility |

## Async Jobs (long tasks)

```bash
tbtools tool-submit expr volcano deg.txt out.svg --timeout 600   # → job_id
tbtools job-status  <job_id>    # running → succeeded / failed / cancelled / timed_out (+ exit_code)
tbtools job-log     <job_id>    # log tail
tbtools job-result  <job_id>    # artifacts + error
tbtools job-cancel  <job_id>    # kill process group (incl. java/xvfb children)
tbtools job-clean   --all       # purge finished jobs
```

## Error Contract

TB001–TB012 error codes with `retryable` + `suggested_action`:

```json
{"exit_code": 2, "error": {"code": "TB002_FILE_NOT_FOUND",
  "retryable": false, "suggested_action": "check the input file path exists"}}
```

Failed runs **also** write provenance (`<output>.tbtools.json` with the error object) — AI can programmatically decide retry vs fix.

## AI Machine Layer (`ai/`)

Generated by `scripts/gen_metadata.py --render` (single source of truth: CommandSpec):

```
ai/manifest.json          entry point + usage
ai/tool-index.jsonl       lightweight index (294 tools: name/group/capabilities/io formats)
ai/capability-index.json  capability → tools (47 capabilities)
ai/workflows.json         4 plan-able workflows (gene family / RNA-seq / comparative / phylogeny)
ai/relations.json         tool relations (accepts/produces/next_step/related_to)
ai/error-codes.json       TB error code registry
ai/tools/<group>/<cmd>.json  per-tool full schema
```

## Exit Code Semantics

| Code | Meaning |
|------|---------|
| 0 | success |
| 1 | invalid argument / engine crash / dependency missing |
| 2 | file not found (TB002) |
| 3 | input format/schema error (TB003/TB004) |
| 4 | out of memory (TB008) |
