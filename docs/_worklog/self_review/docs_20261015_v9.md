### 1.2 命令契约漂移校验（v1.4.23 形态 vs v1.5.2 specs）

**实锤漂移 1 处（P2，有缓解）——recipBlast 示例形态**：

- 教程 4.8 节（L1656-1673）示例：`tbtools recipBlast <query.fa> <subject.fa> rbh`（3 个位置参数，第 3 个为 outPrefix），并写明「v1.4.23 为位置参数形态」。
- v1.5.2 实测：
  - `tool-describe recipBlast --json` 的 inputs 仅 **2 个**（query/subject，均 fasta）；契约层无 outPrefix 槽位；
  - `tool-validate recipBlast seq.fa seq.fa rbh --json` → **valid: false**，第 3 个位置参数 `rbh` 被当文件输入判「文件不存在」；
  - 引擎 help 明确「ArgsParser 风格：参数必须 --key value 形态」，outPrefix 对应 `--outDirAndPrefix`；
  - 历史佐证：v1.4.23 的 command_metadata help 已写「ArgsParser 风格：位置参数会被引擎忽略并静默退出（Bug3 实跑修复）」——即教程的「v1.4.23 位置参数」表述与当时仓库元数据也不完全吻合（CLI 包装层可翻译前 2 个契约位置参数，但第 3 个 outPrefix 不在契约内）。
- **缓解因素**：教程在 L406/537/542/995/1656/1672/2184/2186/2192/2248 等 **10+ 处**反复标注「命令契约一律以本机 `tbtools tool-describe <命令> --json` 为准，不照抄数字」，且步骤①就是先 describe、步骤③就是 `dir` 看实际文件名——按教程流程走的用户会先撞 validate/describe 再执行，不会静默错跑。
- **建议**：教程 4.8 节示例改为契约形态 `tbtools recipBlast <query.fa> <subject.fa>`（outPrefix 走 `--outDirAndPrefix`，或注明「输出在 cwd」），并把「v1.4.23 为位置参数」改为「参数形态以 tool-describe 为准」删除版本锚定。因教程已全局兜底 tool-describe，不定 P1。

**其余命令抽查无漂移**：gxffilter（L1408）、genestructure（L1421）、motif（L1715）示例均只写「先 tool-describe 确认参数风格」而未锚定具体参数形态，与 v1.5.2 CommandSpec 唯一入口现状兼容。教程「找命令用 `tbtools search` / 执行用 `tool-run`」的调用链与 agent-protocol §2 一致。

### 1.3 数字/版本引用的守卫误抓风险（✅ 无）

- `TestCountsSurfaceGuard::test_legacy_drift_values_banned` 扫描面 = 全量 docs/**/*.md（排除 _worklog/self_review/CHANGELOG），**教程在扫描面内**。实扫教程：`213 / 110+ / 180+ / 54 capabilities / 共 82 个工具` → **0 命中**，不触发。

- 教程未引用 218/298/188/80/64/56/49 等任何项目计数（基线节只写「tbtools-cli 1.4.23」不写命令总数）→ 未来计数演进也不会使教程变成漂移面。
- **实跑守卫全绿**：`pytest tests/test_doc_consistency.py tests/test_entrypoint_consistency.py tests/test_cli.py::TestReadmeCounts` → **17 passed**。

**现状已支持，无需 P2 方案**：

1. **固定路径已明文化**：agent-protocol §2 调用链 `search → describe → validate → plan → run → artifact → result → provenance`；README Agent 接口表同构（8 能力编号 1-8）。

3. **别名机制已指向唯一规范名**：`command_spec.py` `KNOWN_ALIASES`（L794，alias→canonical 映射）+ 构建期 `spec.aliases = [反向]`（L914/1012）+ `spec.alias_of`（L920）；describe 输出含 `alias_of` 字段（agent-protocol §6 示例已展示 `"alias_of": null` 形状）。
