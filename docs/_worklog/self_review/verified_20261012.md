## 发现

### P1-1: TTL 严格模式对格式错误 last_passed_at 静默放过(GPT 线索核实属实)

- **位置**: `scripts/gen_metadata.py` L441-448
- **证据**: `_va = _v2.get("last_passed_at") or _v2.get("verified_at", "")`——`"not-a-date"` 为非空真值, 回退不生效; 内层 `except Exception: pass` 对单条解析失败静默跳过, **strict(TBTOOLS_TTL_STRICT=1)与 soft 同样放过**。探针复刻: verified_at=2020 的工具配垃圾 last_passed_at → 超龄判定为空(核验 #8)。且两处兜底均不覆盖: ① 测试模块只读校验循环只断言 verified_at ISO 与 contract_fp 非空, **不校验 last_passed_at 格式**; ② surface 哈希忽略 last_passed_at, render --check 也不会发现。即: 一条损坏/手改的 last_passed_at 可以无限期绕过唯一的新鲜度门禁。
- **触发条件**: 报告文件损坏或手工误改(非机器生成路径), 故不定 P0; 但证据链完整性与 strict 门禁语义被静默架空, 定 P1。
- **修复建议**:
  1. gen_metadata TTL 段: 解析失败时 strict 模式计入失败(`return 1` 或把该条记入 _old_days 以 `(unparseable)` 标注), soft 模式打 warning——去掉裸 `except: pass`;
  2. 测试模块只读校验循环(test_conformance_verified.py `_reported` 块)补 `last_passed_at` ISO 格式断言, 与 verified_at 同检查。

### P2-1: hook 只记录 when=="call", teardown 阶段失败后 call-pass 残留 → 证据错误刷新(GPT 线索核实属实)

- **位置**: `tests/conftest.py` pytest_runtest_makereport(L17-28)
- **证据**: 探针实证(核验 #9): call 通过 + fixture teardown 抛 RuntimeError → 测试项整体 ERROR, 但 TIER2_RESULTS 记录 `"pass"`——`_build_report_and_persist` 会按 pass 刷新该工具 last_passed_at 并写证据。setup 阶段失败/skip 方向是安全的(无 call 报告 → 结果缺失 → 不刷新, 保守)。
- **现实暴露度**: 当前 Tier2 测试只用 tmp_path 等内建 fixture, teardown 失败概率低, 故 P2; 但证据链"只有真 pass 才刷新"的语义存在结构性缺口, 任何未来加的 fixture 终结器/清理失败都会静默穿透。
- **修复建议**: 按完整测试项累积各阶段结果——以 item 为键收集 setup/call/teardown 三份 report, 在 teardown 报告(when=="teardown")处终判: 任一阶段 failed → "fail"; 任一 skipped(且非 call 后 xfail 语义) → "skip"; 三阶段全 passed 才记 "pass"。可用 `item.stash` 或模块级 dict 累积, hookwrapper 内逐阶段写入。

### P3-1: 缺「旧证据 + 本次 fail → 继承且不刷新」正式守卫

- **位置**: `tests/test_conformance_verified.py` TestEvidenceWriteGuard(4 测试)
- **评估**: 现有 3 缺口(fail/skip/缺失无旧证据)+ 1 对照(pass 写证据), 均只覆盖"无旧证据"路径(`_build_with_results` 写入 `{}` 假报告)。「有旧证据 + fail/skip → 继承、verified_at/last_passed_at 不刷、且规整为 details schema」路径只在第五轮手动补测过。52f8b78 的继承规整改动恰好落在该路径——若回归(如继承时误刷 last_passed_at、旧格式条目 KeyError、字段遗漏)现有守卫全部测不到, 静默。**值得补**: 在 `_build_with_results` 基础上预写含旧证据(旧 verified_at/last_passed_at)的假报告 + 注入 fail 结果, 断言继承条目双时间戳未变且字段集 == 六字段 details schema。成本约 20 行, 建议补为第 5 个守卫。
- **优先级**: P3(非阻塞, 防回归网)。
