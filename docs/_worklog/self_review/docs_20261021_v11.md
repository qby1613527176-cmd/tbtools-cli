## 🔴 议题一: params_status 四态宣称 vs 两态实现 —— **证实 GPT,且系已知 P2 复发,仍未闭环**

### 代码实证(command_spec.py:1136-1147,本轮重读)

```python
def params_status(spec) -> str:
    if spec.parameters:
        return "complete"
    return "unknown"
```

函数体内**不存在任何返回 `"partial"` / `"confirmed_none"` 的代码路径**(独立复核,与 GPT 无关地重读源码确认)。docstring 本身诚实(注明 partial=「预留」、confirmed_none=「待逐工具确认后收编」),问题在文档面。

1. **CHANGELOG v1.5.3 条目仍写「P1 params_status 四态: metadata 注入 complete/partial/confirmed_none/unknown」**——与实现/产物不符,属文案过度宣称。**该问题 verified_20261015_v10.md 已定为 P2-1 并给出方案(改 CHANGELOG 措辞为「两态注入,partial/confirmed_none 预留」),但 v1.5.4 发布时只闭环了投影面(ai/tools 补字段),CHANGELOG 措辞未改——已知 P2 跨一轮复发。**

**定级: P2(维持 v10 原判)。** 核心语义「unknown≠none」交付无误,缺陷仅在历史条目文案。
