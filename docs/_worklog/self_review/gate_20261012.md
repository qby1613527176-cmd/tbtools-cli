### P1

**P1-1(gen_metadata.py:441-448): TTL 严格模式下无效时间戳被静默放过——GPT 外部审查线索经独立核实属实**

代码位置(`scripts/gen_metadata.py`):
```python
_va = _v2.get("last_passed_at") or _v2.get("verified_at", "")
if _va:
    try:
        _age = (_now2 - _dt2.datetime.fromisoformat(_va)).days
        if _age > 90:
            _old_days.append((_t2, _age))
    except Exception:
        pass  # 单条 verified_at 解析失败 → 该条 TTL 检查跳过(可容忍, 下轮再查)
```

独立核实(非照抄 GPT 结论): 复刻判定逻辑注入探针, 确认三类逃逸路径:
1. **非 ISO 格式**(`2026/10/11 02:00`、任意垃圾串)→ fromisoformat ValueError → except pass → 该工具 TTL 检查整条跳过, **strict 模式也不红**;
2. **畸形 last_passed_at 遮蔽有效 verified_at**: `or` 只在 falsy 时回退——last_passed_at 是非空垃圾串时不回退 verified_at, 即使 verified_at 是 2020 年超龄值也被一起放过(红队 P1-3 引入 last_passed_at 优先后**新引入**的遮蔽面);
3. **带时区 aware 时间戳**(`+08:00` 后缀)vs naive `datetime.now()` → TypeError → 同样静默跳过。

影响: 若 writeback 写入端未来产生任何非 naive-ISO 时间戳(手动编辑报告/写入端 bug/时区化改造), nightly 的 `TBTOOLS_TTL_STRICT=1` 门禁对这些工具**永久静默失效**, 且无任何告警——比"超龄误报"更危险的反向失效。当前报告 56 条全部健康(bad_format=0/aware=0), 故为潜伏性 P1 而非现行 P0。注释"可容忍, 下轮再查"在 strict 语义下不成立: 解析失败不是"本轮没查到", 是"永远查不到"。

修复建议(strict 失败 / 普通 warning + 工具名):
```python
    except Exception:
        _bad_ts.append((_t2, _va))
# 循环后:
if _bad_ts:
    _bm = "⚠️ 时间戳解析失败: " + ", ".join(f"{t}({v!r})" for t, v in _bad_ts[:8])
    if _ttl_strict:
        print(f"❌ {_bm}(TBTOOLS_TTL_STRICT=1 下视为失败)", file=sys.stderr)
        return 1
    print(_bm)
```

### P2

**P2-1(gen_metadata.py:441): last_passed_at 解析失败时不回退 verified_at。** 与 P1-1 同根因的独立语义缺陷: 即使补上告警, 判定值本身仍应在 last_passed_at 解析失败时回退 verified_at 再判一次(否则"last_passed_at 脏 + verified_at 超龄"的工具即使修了告警也只红不判龄)。建议: try last_passed_at → 失败记 warning 并用 verified_at 重试解析。

**P2-2(onboarding-e2e.yml Step 1/2/3: `tee` 管道无 pipefail)。** `doctor/fetch-jar 2>&1 | tee /tmp/xxx.txt` 吞退出码。但与第五轮 P2-a/b 同类: 每步紧跟 `grep -q "setup --auto"`/`grep -q "已提取"`/`ls -la jar` 步末判定, tee 吞码实际不可达(doctor 失败 → 输出无指引文本 → grep 红)。纯对齐建议, 非必须。

### P3

**P3-1(nightly TTL 步 `| tail -6` 截断)。** `gen_metadata.py --check 2>&1 | tail -6` 保留 pipefail 保真, 但 TTL 红时关键诊断(stderr 的"需人工重验"行)若在输出尾部 6 行之外会被截掉, 增加排障成本。建议 `tail -20` 或失败时重跑不带 tail。仅观测性, 不影响红性。
