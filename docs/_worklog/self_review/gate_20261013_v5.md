## 二、发现

### P2-1 ✅确认(GPT 增量审查): get_jar 通配符候选未展开
- `os.path.isfile("/mnt/c/Users/*/Downloads/...")` 恒 False——候选是字面路径, 普通 Windows 用户 Downloads/Desktop 下的 JAR 永不命中(除非环境变量/其他候选先行命中)
- 修复: 对含 `*` 候选用 glob.glob 展开(仅通配候选走 glob, 无匹配不降级); 或统一交由 find_jar_deep(显式 doctor/setup 场景)

### P2-2 ✅确认(GPT 增量审查): env_fp 缓存非进程级
- _fp_cache 函数内作用域 → 每次调用重建, 数百 MB JAR 重复哈希; docstring 与实际不符
- 修复: 模块级 _ENV_FP_CACHE + (path, mtime_ns, size) 失效检查; GIL 下无锁安全; 测试加 autouse clear 防伪造 mtime; 同步修 docstring

### P2-3 新发现(子代理): get_jar shengwu 路径导致测试环境依赖
- 硬编码机器绝对路径使本机测试非封闭(有 JAR → doctor find → 测试走真 JAR 分支)
- 修复: 测试用 monkeypatch 覆盖 get_jar 返回值, 而非依赖候选列表真实命中
