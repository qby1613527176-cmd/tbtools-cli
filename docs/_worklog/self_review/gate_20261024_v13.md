## 1. 🟠 GPT 潜在风险 2：CI 绿 ≠ 真实引擎端到端 —— **P3（实质已覆盖，残余为粒度/报告分立）**

**现状核实（与 GPT 描述有两处出入，需修正）：**

1. **「nightly 是否有真实 JAR 环境」——有，且比 GPT 认知的深。** `nightly-e2e.yml`（每日 01:00 UTC + workflow_dispatch）：`fetch-jar --yes` 静默下载真实 JAR → `doctor` 断言 sha256 → `xvfb-run bash scripts/e2e_nightly.sh` 跑 **10+ 代表命令 × 真实 examples 数据**（volcano/msy/rooting/dualsyn/tableCollapse/hclust/gxfSplit/venn2 等，断言退出码 0 + 产物非空）。且 nightly 还跑 **conformance 执行验证全量 + writeback PR**（`TBTOOLS_WRITE_REPORT=1` 刷新 `verification_report.json` + render AI manifest + `TBTOOLS_TTL_STRICT=1 --check`），主分支的 56 条 EXECUTION_VERIFIED 证据由该链路**持续保鲜**，不依赖人工。
