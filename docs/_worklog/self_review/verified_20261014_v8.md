## 发现

### P1-1 🔴 env 空指纹条目在加载端被保留为 CONFORMANCE_VERIFIED(GPT 发现, 独立实证成立)

**代码证据**(command_spec.py `_load_verification_report` L1188):
```python
if _old_env:
    ...比对, 不一致则 discard...
```
`_old_env` 为空串时整个 env 比较被跳过; 而契约分支有 `elif not _old_fp: discard`(L1185-1187)。两端不对称: **写入端(十二轮)把"env 不可确认"保守置空, 加载端却把空 env 当"无需比较=保留"**。

**探针实证**(隔离子进程, 临时改写 tests/verification_report.json 后 reload, 已还原):
- 条目 `{level: CONFORMANCE_VERIFIED, contract_fingerprint: <当前真fp>, env_fingerprint: ""}` →
  `RESULT conf=True level=CONFORMANCE_VERIFIED` —— **身份不可确认的证据被接受为已验证**
- 对照(contract_fp 也置空) → `conf=False level=COMPILEABLE`(正确 discard)

**语义后果**: 无 JAR 环境跑出的金链 pass(env 置空)写入的报告, 在**任何** env 下加载都保留金链级——env_fingerprint 机制对该类条目完全失效, 与"缺 fp 即 discard"不变量(L1186 注释自称)矛盾。

**修复方案**: 加载端对齐契约分支语义——
```python
elif not _old_env:
    _exec.discard(_t); _conf.discard(_t)   # env 身份不可确认 → 不保留
```
(或折中: 空 env 仅当 `TBTOOLS_JAR` 显式指向的 JAR 可算 env_fp 且与 `prev_env_fingerprint` 不一致时 discard——但简洁起见建议直接 discard, 保守即正确。)
**回归守卫**: 新增加载端测试——env_fp="" + 匹配 contract_fp 条目必须不进 EXEC/CONF 集合(现有 `test_conformance_no_inherit_on_empty_fp` 只覆盖写入端继承路径, 加载端无对应不变量测试)。

### P1-2 🟠 --threads 透传破坏位置线程参数工具 parallelMD5Check(GPT 发现, 独立实证成立)

**代码证据**:
- cli_load.py L336-337: `_cmd_impl` 无条件 `args.extend(["--threads", str(threads)])`(impl 与 bash 兜底两路均然, L347-348)
- auto_commands.py L1135-1152 `_parallelMD5Check_impl`: `parallelMD5Check <md5_list.txt> [threads]` —— `args[1]` 即线程数且要求 `isdigit()`

**探针实证**:
```python
impl([lst, "--threads", "8"])  # 透传后形态
→ ❌ threads 须为数字: --threads   ec=2
```
用户 `tbtools parallelMD5Check list.txt -t 8` 必硬失败(ec=2)——不是静默降级, 是**功能被破坏**; 比十二轮前的"静默丢弃线程数"更糟(由无提示降级变为报错拒跑)。

**影响面核查**: 全文件 grep 位置线程参数仅 parallelMD5Check 一处(`[threads]`); fqTrim/kallisto/muscle/findBestHomologyBatch 均 named `--threads` 形态, 透传对它们恰好是修复。L1049 synteny 类解包 `args[0..3]` 不受尾部追加影响。**破坏面 = 单工具, 但该工具被十二轮"修复"打成必挂**。

**修复方案**: 契约层加线程参数形态三态标记(如 registry/impl 元数据 `thread_style: named_flag|positional|unsupported`), 透传按形态适配:
- `named_flag` → 追加 `--threads N`(现行为)
- `positional` → 追加裸 `str(N)`(且仅当用户未已在位置参数给过)
- `unsupported` → 透传前告警"该工具不支持 --threads, 忽略"
另加正整数校验(click `type=int` 已挡非数字, 但 `-t 0/-3` 未挡)。
