### P1(错误, 需修)

**P1-1 docs/COMMAND_REFERENCE.md:1033 "共 82 个工具"——数字错误 + 表内混入 2 个非 tool 条目**
- 证据: 章节标题(L1022)已修为 `## 三、CLI 工具 tbtools tool（80）`, 但同节正文 L1033 仍写 "共 **82** 个工具，按功能分类："——**文档内部自相矛盾**(与第五轮 P1#5 完全同类的"改标题漏正文"残留, 本轮 d6728be/22e4f77/9511358 三 commit 均只改 L1022)。
- 实测: 该节表格实有 **82 行**, 但与代码 `build_command_specs()` 的 `kind=='tool'`(80 个)diff, 多出 `mimicVqsr`、`vcfAddID`——两者在 specs 中 **kind='direct'**, 不属于 tool 小节。即不止数字错, 分类也错(2 个 direct 命令被归进 CLI 工具节)。
- 修复建议: ① L1033 "82"→"80"; ② 将 mimicVqsr/vcfAddID 两行移出第三节(归入 direct 命令对应章节或删); ③ 移完后表格行数应与 counts.md tools=80 机器对齐。

**P1-2(守卫缺口)TestCountsSurfaceGuard / legacy 禁回扫描面过窄——两处现存漂移全部落在覆盖外**
- 证据: 守卫句式比对与 `test_legacy_drift_values_banned` 只扫 5 个文件(README/README_EN/index/quickstart/agent)。本轮实测 **docs/faq.md:3(110+)** 与 **docs/COMMAND_REFERENCE.md:1033(82)** 两处活跃漂移恰好都在扫描面之外——守卫对它们零感知, "漂移无感再生"结构在非门面文档上仍未堵。
- 另: legacy 黑名单(213/110+/180+/54 capabilities)不含 "82 个工具"/"66" 等第五轮已修值, 即使扫到 COMMAND_REFERENCE 也抓不住 82。
